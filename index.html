Chequeador de hipótesis de funcionamiento

Herramienta didáctica para revisar la estructura de una hipótesis. No determina si la hipótesis es verdadera: ayuda a identificar qué elementos necesita para poder ser discutida y puesta a prueba.

Después del chequeo, reescriban la hipótesis incorporando los elementos que falten. No busquen “poner palabras obligatorias”: intenten hacer explícita la relación causal.

El PDF se genera directamente en este dispositivo. Si la base del curso está configurada, la entrega también puede guardarse allí.
